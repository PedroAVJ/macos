## messages (NOTICE.md)

The plugin independently implements a minimal plain-text decoder for the `NSAttributedString` typedstream representation observed in modern macOS Messages databases. The implementation was informed by public documentation from the MIT-licensed Madrid project and the MIT-licensed `imessage-parser` project; no source code from either project is included.

Apple, iMessage, and macOS are trademarks of Apple Inc. This project is not affiliated with or endorsed by Apple Inc.

## apple-passwords (PROVENANCE.md)

The `apple-passwords` package was migrated from the original local authoring files
maintained by PedroAVJ. The original authoring folders remain preserved outside
this repository. Installed client caches were not used as canonical source.
The publication task retains the exact source paths and source hashes privately.

The first-party source, portable packaging changes, and original vector artwork
are released under the MIT license in `LICENSE`. No user credential, account
configuration, device snapshot, or operational screenshot is part of this
public package.

The `credential-authorization` skill, `native/MacBookCredentialBroker.swift`,
`runtime/bin/macbook-credential-broker`, the broker scripts, `.mcp.json`, and the
broker tests moved unchanged from the MIT-licensed `PedroAVJ/macbook` repository
at commit `23745c9775f1463a3a2996326178b634685d3953`.
